## Contribution
1. Fork the repository
2. Go to the folder `collection 5`
3. Add your wallpapers there
   - image naming needs to match the [naming scheme](#naming-scheme)
   - format should be either `png` or `jpg`
4. Stage, commit, push
5. Open PR with structured description of what u have done, and wait for it...

### OR

1. Go to [wallpaper-suggestions](https://github.com/Firefly-SL/wal-collection/discussions/1)
2. Draft a comment in this format
```txt
1. example.com/img1 
2. example.com/img2
3. example.com/img3
```
or, with name that follows [naming scheme](#naming-scheme)
```txt
1. [blue1](example.com/img1)
2. [blue2](example.com/img2)
3. [red1](example.com/img3)
```
3. Post and wait for it...

## Naming Scheme

> [short for your name]-[color][count]

- `your name`, github username is recommended
  - keep it short and lowercase (Firefly-SL to firefly)
  - use the same name for all your wallpapers in the collection
- `color` is the primary color in the image
  - use basic color name (red, brown, green, etc..)
  - don't use complex color name (light green, sky blue, dark red, phlox, etc.)
- `count` is the number added at the end of the filename to overcome duplication issue
  - it is mandatory, even if there is no file with similar name

```txt
firefly-blue1.png
firefly-blue2.png
firefly-brown1.png
```
